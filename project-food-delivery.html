AI Food Delivery Platform

A recommendation-driven food delivery web app that connects customers with home chefs using AI intelligence.

Project Overview

This project showcases an AI-enabled food delivery platform designed to help users discover nearby home chefs and personalized meal recommendations.

The platform includes user profiles, chef listings, intelligent menu suggestions, and an optimized ordering workflow.

Key Features

  • AI-powered recommendations for dishes and chefs.
  • Responsive front-end with intuitive ordering flow.
  • Chef profiles, cuisines, and delivery scheduling.
  • Structured service matching between customers and home cooks.
